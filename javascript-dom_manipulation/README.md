In this folder, we will learn about JavaScript DOM manipulation.

### Learning objectives

How to select HTML elements in JavaScript  
    With the querySelector method we can select an element in a html file. If we use the querySelectorAll, we can select all the element in a html file, for exemple the paragraph (querySelectorAll("p)).
What are differences between ID, class and tag name selectors  
    The id (#) is selected before the class (.), that selected before the tag name (for exemple, p).
How to modify an HTML element style     
    Using the style method. For exemple, using style.color("red") to change the color of a text.
